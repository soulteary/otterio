# Release guide / 发布指南

See the [maintainer release guide](../releasing.md) for signing and pushing a
release tag, required CI, registry configuration, verification and recovery.
The reviewed notes for the next release are in [RELEASE_NOTES.md](../../RELEASE_NOTES.md).

完整发布步骤见[维护者发布指南](../releasing.md)，包括标签签名、CI 检查、镜像仓库配置、
产物验证及失败恢复。本次中英双语更新说明及匿名致谢见 [RELEASE_NOTES.md](../../RELEASE_NOTES.md)。

社区贡献者致谢与私人安全反馈的匿名致谢，统一记录于 [ACKNOWLEDGMENTS.md](../../ACKNOWLEDGMENTS.md)；发布前核对本次说明与对应版本说明中的署名和贡献归属。
